# Bug Fix Workflow

1. Reproduce or locate the failure signal.
2. Trace the failing path from evidence.
3. Separate root cause from symptoms.
4. Write or identify a regression test when practical.
5. Patch minimally.
6. Run targeted validation.
7. Inspect diff for unrelated changes.
8. Report evidence and remaining uncertainty.
